# Contributing to RomMate

Thanks for your interest in contributing!

## How to contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Reporting bugs

- Open an issue on GitHub
- Include your OS, app version, and steps to reproduce

## Translations

RomMate supports 9 languages. To add or improve a translation:
- Translation files are in `locales/<language>/LC_MESSAGES/rommate.po`
- Edit the `.po` file and open a Pull Request

## Code style

- Follow existing code style
- Keep commits clean and descriptive
- Test on both Windows and Linux if possible
